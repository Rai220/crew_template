# Среда

Источник: поставка пустого шаблона, 2026-11-10. Реальное окружение еще не проверено

Рабочие проекты и удаленные ресурсы не настроены. Для первой задачи проверь текущую машину и корень репозитория. Добавь только согласованные пути и ссылки на карточки систем

Для каждого ресурса: назначение, машина, проверенный путь, разрешенные операции, источник разрешения, дата и способ проверки. Для секретов допустим только указатель на разрешенное хранилище
