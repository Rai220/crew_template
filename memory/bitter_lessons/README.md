# Горькие уроки

Пока пусто. Сюда записывай ошибки с существенной ценой и долгие неудачные подходы: потерянное время, потраченный бюджет, испорченные результаты, повторение уже известной проблемы

Каждый урок - отдельный файл с метаданными `name`, `description`, `type: bitter_lesson`, `updated`. Добавляй сюда краткое описание и Markdown-ссылку. Образец - [bitter_lesson.md](../../examples/bitter_lesson.md)

В уроке нужны исходная задача, что пробовали, наблюдаемый результат, цена ошибки (если измерена), подтвержденная причина или честно отмеченная гипотеза, что делать в следующий раз и границы применимости. Обязательны источник и ссылка на запись в журнале задач

Перед похожей задачей ищи здесь по теме. Не превращай единственный провал в вечный запрет: при новых данных пересмотри вывод, сохранив историю. Обычные переносимые выводы остаются в lessons; один и тот же текст в двух папках не дублируй
