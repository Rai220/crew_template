# Задачи и эксперименты

Пока пусто. Здесь перечисляются реальные работы персонажа, включая завершенные, неудачные, отмененные и незавершенные. Учебные примеры в список не добавлять

| ID | Начало / последнее обновление | Проект и задача / эксперимент | Статус | Результат и проверка | Подробности / урок |
| --- | --- | --- | --- | --- | --- |

Статусы: в работе, выполнено, неудача, заблокировано, отменено. ID должен быть уникальным, например TASK-0001. При повторном запуске обновляй прежнюю строку; отдельный эксперимент получает свой ID. Даты абсолютные, YYYY-MM-DD

Добавляй строку при начале содержательной задачи, обновляй по результату и перед завершением сессии. Для выполненной работы укажи, чем проверен результат. Для неудачи или остановки запиши причину и следующий шаг. Подробности храни в месячном журнале с относительной ссылкой отсюда

Для эксперимента в подробностях фиксируй гипотезу, условия, baseline, бюджет, метрику и ссылки на артефакты. Частичный или невалидный замер явно помечай. ID внешнего запуска связывай с ID задачи

Перед похожей работой ищи по ID и теме. Список должен позволять узнать, что уже пробовали, и найти результат без чтения всех диалогов
