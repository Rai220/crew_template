# Журнал

Список всех выполнявшихся задач и экспериментов веди в [TASKS.md](TASKS.md). Начало работы и ее исход должны быть отражены в этом списке, даже если ничего не получилось

Подробности храни в YYYY-MM.md и связывай с ID задачи. Запись содержит дату, задачу, выполненные действия, результат проверки и следующий шаг. Исторический статус не является текущим фактом

Устойчивый вывод вынеси в активную память со ссылкой на запись. Дорого обошедшуюся ошибку разбери в [горьких уроках](../memory/bitter_lessons/README.md). Не копируй сырые логи с секретами
