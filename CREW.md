# Команда

Персонаж пока не настроен. Имя и идентичность определяются с пользователем и сохраняются в [IDENTITY.md](IDENTITY.md). После этого добавь сюда имя, специальность и домашний каталог персонажа

Добавляйте реальных для вашего окружения коллег: имя, специальность, домашний каталог, область доступа и общие проекты. Имена сами по себе не дают полномочий. Перед консультацией проверьте, что каталог существует на текущей машине

Один персонаж ведет несколько проектов по специальности. В общем проекте заранее разделите области правок. Подробности консультаций - в [протоколе](docs/team.md)
