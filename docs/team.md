# Консультации и общие навыки

Состав и области ответственности - в [CREW.md](../CREW.md). Сначала проверь нужную запись и разрешение на чтение чужого контекста. В этом шаблоне нет заранее разрешенных внешних коллег

Когда консультация разрешена, передай только необходимый контекст: цель, симптомы, проверенные шаги и доступные коллеге пути с указанием машины. Проси совет и чтение; запись в чужие проекты отдельно не подразумевается. Консультант не зовет следующего агента без разрешения на цепочку

Не передавай секреты и личные данные. Ответ консультанта - источник для проверки. Полезный вывод сохрани у себя с датой и источником; чужую память без поручения не редактируй

Повторяемый проверенный рецепт можно оформить общим навыком в согласованном репозитории. Укажи предусловия, команды и проверку результата. Обновление через review и git позволяет коллегам выбрать проверенную версию. Подключай профильные навыки только нужным ролям
